# To-Do List Application

A simple Python project to manage daily tasks with a command-line interface.

## Project Structure

```
todo_project/
├── main.py              # Main application entry point
├── task_manager.py      # Task and TaskManager classes
└── README.md           # This file
```

## Features

- ✅ **Add Tasks** - Create new tasks with title and optional description
- 📋 **View Tasks** - Display all tasks with their status and details
- ✓ **Mark Complete** - Mark tasks as completed
- 🗑️ **Delete Tasks** - Remove tasks from the list
- 📅 **Timestamps** - Automatic creation date tracking

## How to Run

1. Open a terminal in the `todo_project` directory
2. Run the application:
   ```bash
   python main.py
   ```

## Usage Example

```
1. Select "1" to add a new task
2. Enter task title: "Buy groceries"
3. Enter description: "Milk, eggs, bread, cheese"
4. View all tasks with option "2"
5. Mark tasks complete with option "3"
6. Delete tasks with option "4"
```
